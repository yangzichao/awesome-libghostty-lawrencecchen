# Contributing

Thanks for contributing to `awesome-libghostty`.

## Inclusion Criteria

A submission should satisfy at least one:

- Uses `libghostty` or `libghostty-vt` directly.
- Embeds Ghostty technology in a terminal-related product.
- Is a high-value resource for builders in this ecosystem.

And all of these:

- Publicly accessible link.
- Clear one-line description.
- Not obviously abandoned or spam.

## Pull Request Checklist

- Add the project in the correct section.
- Keep descriptions concise and factual.
- Keep alphabetical ordering within a section when practical.
- If the project is closed source, label it clearly.
- Include at least one source link that supports the claim.
