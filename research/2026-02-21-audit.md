# Ecosystem Audit (2026-02-21)

This audit was performed to keep the README limited to projects with clone-verifiable Ghostty usage.

## Discovery Method

Initial discovery queries:

- `gh search repos "libghostty" --limit 100`
- `gh search repos "libghostty-vt" --limit 100`
- `gh search repos "ghostty-based" --limit 100`
- `gh search code "libghostty" --limit 100`
- `gh search code "GhosttyKit" --limit 100`

## Clone Verification Method

Each GitHub repository linked from README was refreshed locally from source and checked with filesystem tooling.

Clone/refresh:

```bash
while read -r repo; do
  target="$HOME/.agent-repos/${repo%%/*}/${repo##*/}"
  if [ -d "$target/.git" ]; then
    git -C "$target" fetch --depth 1 origin HEAD
    git -C "$target" reset --hard FETCH_HEAD
  else
    git clone --depth 1 "https://github.com/$repo" "$target"
  fi
done
```

Evidence checks (examples):

- `rg -n -i '(libghostty|libghostty-vt|GhosttyKit|ghostty-web|ghostty-org/ghostty)' <repo>`
- Verified matches in non-markdown files (build files, source, deps, bindings).
