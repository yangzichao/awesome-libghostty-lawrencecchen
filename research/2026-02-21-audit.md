# Ecosystem Audit (2026-02-21)

This audit was performed before initializing this repository to ensure entries are based on recent, verifiable projects.

## Discovery Method

The following GitHub searches were used:

- `gh search repos "libghostty" --limit 100`
- `gh search repos "libghostty-vt" --limit 100`
- `gh search repos "ghostty-based" --limit 100`
- `gh search code "libghostty" --limit 100`
- `gh search code "GhosttyKit" --limit 100`

Top candidates were then shallow-cloned locally and inspected with filesystem tools (`rg`, `sed`) for README claims and code-level evidence.

## Exclusions

Some projects found during search were excluded from the main list for one or more reasons:

- Primarily themes, icons, or shell setup repositories rather than libghostty-based software.
- Repositories with minimal technical signal (placeholder, no implementation, or no substantive README/code evidence).
- Internal/fork-style snapshots that did not add distinct ecosystem value beyond upstream projects.
